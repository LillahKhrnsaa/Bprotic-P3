📏 HC-SR04 · Sensor Jarak

Mengukur jarak dengan memantulkan bunyi ultrasonik, seperti sonar kelelawar.

CARA KERJA

Empat langkah

1. Arduino memberi pulsa 10 µs ke pin TRIG.
2. Sensor memancarkan 8 gelombang ultrasonik 40 kHz (tidak terdengar manusia).
3. Pin ECHO menjadi HIGH sampai pantulan kembali.
4. Lama HIGH itu = waktu tempuh bunyi, diukur dengan pulseIn().

RUMUS

Dari waktu ke jarak

Kecepatan bunyi ≈ 343 m/s = 0,0343 cm/µs. Bunyi menempuh pergi dan pulang, jadi dibagi 2:

jarak = durasi × 0,0343 / 2 (cm)
jarak ≈ durasi / 58 (cm)
Durasi echoJarak
580 µs10 cm
1160 µs20 cm
2900 µs50 cm
5800 µs100 cm
Jangkauan efektif 2-400 cm. Pin: VCC (5V), TRIG, ECHO, GND. Permukaan lunak (kain, busa) memantulkan bunyi lebih buruk daripada permukaan keras.

💻 HC-SR04 · Kode & Lab

Dua cara membaca jarak: manual dengan pulseIn(), atau pakai library NewPing.

CARA 1 · MANUAL

pulseIn()

digitalWrite(TRIG, LOW); delayMicroseconds(2);
digitalWrite(TRIG, HIGH); delayMicroseconds(10);
digitalWrite(TRIG, LOW);
long durasi = pulseIn(ECHO, HIGH);
int jarak = durasi / 58;
CARA 2 · LIBRARY

NewPing

#include <NewPing.h>
NewPing sonar(2, 3, 200); // TRIG, ECHO, max cm
int jarak = sonar.ping_cm();
Install: Sketch → Include Library → Manage Libraries, cari NewPing, klik Install. ping_cm() mengembalikan 0 jika tidak ada pantulan / di luar jangkauan, jadi cek jarak > 0 sebelum dipakai.

🌡️ DHT11 · Suhu & Kelembaban

Dua sensor dalam satu modul, data keluar lewat satu kabel.

KOMUNIKASI DIGITAL

Kenapa butuh library?

DHT11 mengirim data sebagai deretan pulsa digital di satu pin DATA. Satu pembacaan = 40 bit (5 byte): kelembaban (2 byte), suhu (2 byte), dan checksum (1 byte) untuk mengecek data tidak rusak. Mengatur timing pulsanya manual itu rumit, jadi kita pakai library.

Install: Manage Libraries → DHT sensor library (Adafruit) → Install. Kalau diminta, install juga Adafruit Unified Sensor.
SPESIFIKASI

Yang perlu diingat

ParameterNilai
Suhu0-50°C (±2°C)
Kelembaban20-90% (±5%)
Tegangan3,3 - 5V
Kecepatan bacamaks. 1× per detik
PinVCC, DATA, GND
⚠ Modul 3 pin biasanya sudah ada resistor pull-up. Kalau memakai sensor 4 pin polos, pasang resistor ±10kΩ antara VCC dan DATA.

💻 DHT11 · Kode & Lab

Baca suhu dan kelembaban, lalu cek apakah pembacaannya valid.

#include <DHT.h>
DHT dht(4, DHT11); // pin DATA, tipe sensor

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float t = dht.readTemperature(); // °C
  float h = dht.readHumidity(); // %
  if (isnan(t) || isnan(h)) {
    Serial.println("DHT error");
    return;
  }
  digitalWrite(LED, t > 30);
  delay(1000);
}
Gagal baca menghasilkan NaN (Not a Number). Selalu cek dengan isnan() sebelum nilainya dipakai di if/else.

📟 Membaca Dua Sensor ke Serial

Gabungkan HC-SR04 dan DHT11, tampilkan rapi di Serial Monitor.

void loop() {
  int jarak = sonar.ping_cm();
  float t = dht.readTemperature();
  float h = dht.readHumidity();

  Serial.print("Jarak: "); Serial.print(jarak);
  Serial.print(" cm | Suhu: "); Serial.print(t);
  Serial.print(" C | Lembab: "); Serial.print(h);
  Serial.println(" %");
  delay(1000);
}
💡 Satu delay(1000) memenuhi syarat DHT11 (maks 1× per detik) sekaligus membuat output Serial tidak terlalu cepat dibaca.

🖥️ LCD 16x2 I2C · Tampilkan Data

Robot punya layar sendiri, tanpa perlu laptop dan Serial Monitor.

KONSEP

Kenapa I2C?

LCD 16x2 = 16 kolom × 2 baris. LCD biasa butuh sekitar 6 pin data. Dengan modul I2C cukup 2 kabel: SDA (data) dan SCL (clock). Di Uno: SDA = A4, SCL = A5. Modul ini punya alamat (umumnya 0x27, kadang 0x3F).

#include <Wire.h>
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  lcd.init();
  lcd.backlight();
}
void loop() {
  lcd.setCursor(0, 0); // kolom 0, baris 0
  lcd.print("Jarak: "); lcd.print(jarak); lcd.print(" cm ");
  lcd.setCursor(0, 1); // baris ke-2
  lcd.print("Suhu: "); lcd.print(t); lcd.print(" C ");
}
Install library LiquidCrystal I2C lewat Manage Libraries. Layar kosong tapi lampu menyala? Putar potensiometer kontras di belakang modul, atau coba alamat 0x3F.

IDE UTAMA

Dari 3 aksi jadi nilai kontinu

Pakai 5-8 sensor untuk menghitung posisi garis (error). Makin jauh dari tengah, makin besar koreksinya. Kecepatan roda kiri dan kanan diatur dengan PWM (ingat P2!).

koreksi = Kp × error
        + Ki × (jumlah error lama)
        + Kd × (error − error sebelumnya)

P = seberapa jauh dari garis sekarang.
I = akumulasi kesalahan yang lama.
D = seberapa cepat error berubah (peredam goyangan).

Bandingkan langsung

Posisi garis
Kp
Negatif = garis di kiri, positif = garis di kanan. Versi biasa hanya punya nilai 0 atau penuh. Versi PID mengubah kecepatan roda bertahap, jadi gerakannya halus. (Di sini baru bagian P, I dan D menyusul di pertemuan nanti.)
CUPLIKAN KODE

Gambaran logika PID

// 5 sensor, bobot -2 -1 0 1 2
posisi = (-2*s0 - s1 + s3 + 2*s4) / (s0+s1+s2+s3+s4);
error = posisi; // target = 0 (tengah)
P = Kp * error;
I = I + error;
D = error - errorLama;
koreksi = P + Ki*I + Kd*D;
errorLama = error;
analogWrite(PWM_KIRI, constrain(BASE + koreksi, 0, 255));
analogWrite(PWM_KANAN, constrain(BASE - koreksi, 0, 255));
💡 Tuning: mulai dengan Kp saja (Ki = Kd = 0), naikkan sampai robot mulai bergoyang lalu turunkan sedikit. Tambah Kd untuk meredam goyangan. Ki terakhir, kecil, atau tidak dipakai.
